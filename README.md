# Лабораторные работы по веб-программированию

Учебные работы на HTML, CSS, JavaScript, TypeScript и C#: интерактивные страницы, браузерные игры, анимации и консольные задачи. Отдельная работа посвящена React.

Каждая работа находится в собственной папке. Нумерация и буквенные суффиксы сохранены в названиях каталогов.

## Описание работ

| Работа | Тема | Что реализовано |
| --- | --- | --- |
| [1б — `lab1b`](lab1b/) | Генератор цветовой палитры | Создание палитры из пяти случайных цветов, отображение HEX-кодов и копирование выбранного кода в буфер обмена. Кнопка генерирует новую палитру. |
| [2а — `lab2a`](lab2a/) | Генератор паролей | Генерация пароля длиной восемь символов. В каждом пароле есть строчная и заглавная латинские буквы и специальный символ; цифры входят в общий набор, но их наличие не гарантируется. |
| [2б — `lab2b`](lab2b/) | Проверка пароля | Проверка пяти условий при вводе: длина от восьми символов, заглавная и строчная буквы, цифра и специальный символ. Есть индикатор выполнения условий и переключатель видимости пароля. |
| [3 — `lab3`](lab3/) | Генератор случайных чисел | Выбор случайного целого числа в заданном диапазоне, включая обе границы. Проверяются пустые поля, целочисленность и порядок границ. |
| [3а — `lab3a`](lab3a/) | Переключение темы | Переключение светлого и тёмного оформления страницы с изображением и текстом. Надпись на кнопке меняется вместе с темой; после обновления страницы тема сбрасывается. |
| [4 — `lab4`](lab4/) | Игра «Угадай число» | Угадывание числа от 1 до 100 с подсказками «больше/меньше», историей и счётчиком попыток. Есть проверка ввода, картинки-реакции и запуск новой игры. |
| [4а — `lab4a`](lab4a/) | Игра «Котики против фото» | Игра для двух человек на одном устройстве: поле 5 × 5, победа за три символа подряд по горизонтали, вертикали или диагонали. Учитываются завершённые раунды и победы; после раунда можно начать следующий. |
| [5 — `lab5`](lab5/) | Счётчик кликов на React | Увеличение и уменьшение числа кнопками, включая отрицательные значения. Состояние хранится через `useState`, а `useEffect` сохраняет его в `localStorage`, чтобы восстановить после обновления страницы. Для запуска и сборки используется Vite. |
| [6 — `lab6`](lab6/) | Анимация круга | Четыре последовательных клика: увеличение круга с изменением цвета, уменьшение до исходного размера, замена заливки контуром и удаление элемента. Анимации заданы в CSS. |
| [7 — `lab7`](lab7/) | Печатная машинка | Посимвольный вывод введённого текста через `requestAnimationFrame`. «Старт» начинает печать заново, «Стоп» прерывает её и сохраняет уже выведенный текст. |
| [1а на C# — `labsC#/lab1a`](labsC%23/lab1a/) | Числа, строки и массивы | Консольные упражнения: проверки чисел, работа с цифрами и строками, арифметические операции, объединение, сортировка и фильтрация массивов, поиск символов и подсчёт элементов. Проект для .NET 10. |
| [1 на JavaScript — `labsJS/lab1`](labsJS/lab1/) | Числа, строки и массивы | Набор консольных функций для работы со случайными числами, строками и массивами: сравнение, арифметика, сортировка, объединение и фильтрация. Запуск через Node.js; функции подключаются через `require`. |
| [2 на TypeScript — `labsTS/lab2`](labsTS/lab2/) | Типизированные консольные задачи | Упражнения с числами, строками и массивами с указанием типов параметров, результатов и переменных. В том числе сортировка, поиск цифр и отбор отрицательных чисел, кратных семи. |

Подробные описания также есть у [игры «Угадай число»](lab4/README.md), [игры «Котики против фото»](lab4a/README.md) и [счётчика на React](lab5/README.md).

## Запуск

Склонируйте репозиторий и перейдите в его корень:

```sh
git clone https://github.com/gusilebediflipflop228/LabsForWebProgramming.git
cd LabsForWebProgramming
```

Все следующие команды приведены относительно корня репозитория.

### Страницы на HTML, CSS и JavaScript

Для `lab1b`, `lab2a`, `lab2b`, `lab3`, `lab3a`, `lab4`, `lab4a`, `lab6` и `lab7` откройте `index.html` из нужной папки в современном браузере. Установка зависимостей не требуется.

Для запуска через локальный сервер нужен Python 3:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Затем откройте, например, [игру «Угадай число»](http://127.0.0.1:8000/lab4/) или [печатную машинку](http://127.0.0.1:8000/lab7/). Для другой работы замените имя папки в адресе. Остановить сервер можно сочетанием `Ctrl+C`.

### React — `lab5`

Нужны Node.js и npm. Версия Vite в проекте требует Node.js 20.19+ в ветке 20 либо 22.12 и новее; для единого окружения с TypeScript-работой можно использовать Node.js 24.

```sh
cd lab5
npm ci
npm run dev
```

Откройте адрес, который появится в терминале, обычно `http://127.0.0.1:5173`. Остановка — `Ctrl+C`.

Сборка и просмотр её результата выполняются из папки `lab5`:

```sh
npm run build
npm run preview
```

Сборка сохраняется в `lab5/dist/`. Значение счётчика сохраняется в текущем браузере для того же адреса и порта.

### JavaScript — `labsJS/lab1`

Нужен Node.js:

```sh
node labsJS/lab1/main.js
```

Результаты выводятся в терминал. Список запускаемых упражнений находится в `main.js`; вызов `firstTask()` сейчас закомментирован.

### TypeScript — `labsTS/lab2`

Для прямого запуска исходных `.ts`-файлов используйте Node.js 24, поддерживающий выполнение используемого здесь TypeScript-синтаксиса без отдельной сборки:

```sh
node labsTS/lab2/main.ts
```

Результаты выводятся в терминал. Такой запуск не проверяет типы. Если установлен компилятор TypeScript, проверку можно выполнить отдельно:

```sh
tsc --project labsTS/lab2/tsConfig.json
```

Имя конфигурации в репозитории — именно `tsConfig.json`; параметр `--project` указывает его явно. Настройка `noEmit` отключает создание JavaScript-файлов при проверке типов.

### C# — `labsC#/lab1a`

Нужен .NET SDK 10:

```sh
dotnet run --project "labsC#/lab1a/lab1a.csproj"
```

Результаты выводятся в терминал. `Program.cs` запускает упражнения, а их реализации находятся в `LabTasks.cs`.

## Организация файлов

- В обычных веб-работах `index.html` задаёт структуру страницы, `style.css` или `styles.css` — оформление, а `script.js` — поведение.
- В `lab5/src/` находятся React-компонент и стили; команды запуска описаны в `lab5/package.json`.
- В `labsJS/lab1` и `labsTS/lab2` файл `main` запускает функции из модуля с упражнениями.
- `.gitignore` исключает настройки IDE, файлы macOS, установленные зависимости и результаты сборки.
