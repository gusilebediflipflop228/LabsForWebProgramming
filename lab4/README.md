# Лабораторная работа № 4 — «Угадай число»

Игра на чистом JavaScript с HTML и CSS, без библиотек и сборки.

## Запуск

Открой `index.html` двойным кликом в браузере. Интернет и установка пакетов не нужны.

Если браузер запрещает хранилище для локальных файлов, запусти из папки `lab4`:

```sh
python3 -m http.server 8000
```

Затем открой <http://localhost:8000>. Остановить сервер: `Ctrl+C` в терминале.

## Как играть

1. Введи целое число от 1 до 100.
2. Нажми кнопку «Проверить».
3. При неверной попытке появятся картинка «Хорошая попытка, но нет!» и подсказка: загаданное число больше или меньше введённого.
4. При правильном ответе появятся картинка победы и надпись «Число угадано!», ввод заблокируется.
5. Кнопка «Новая игра» загадывает другое число и очищает историю.

Попытки не ограничены. История показывает все допустимые ответы в порядке ввода, включая повторные и победный. Пустое поле, дроби и числа вне диапазона вызывают сообщение об ошибке и не считаются попытками. История относится к текущей игре и очищается при обновлении страницы.

## Файлы

- `index.html` — разметка: поле ввода, подсказка, история и кнопки.
- `style.css` — цветной фон и оформление карточки для компьютера.
- `script.js` — генерация числа, проверка ответа, история и перезапуск.
- `zero-reaction.png` — картинка для специального сообщения при вводе нуля.
- `wrong-reaction.png` — картинка для неверной попытки.
- `success-reaction.png` — картинка при правильном ответе.

В HTML, CSS и JavaScript есть комментарии на русском, объясняющие основные блоки.

## Как устроена программа

`secretNumber` хранит загаданное число, `guesses` — массив принятых ответов, `isFinished` — признак завершения игры.

`generateNumber()` выбирает случайное целое число. При наличии предыдущего секрета он исключается из возможных вариантов: результат обязательно отличается. Предыдущее число хранится в `sessionStorage`, которое сохраняется при обновлении текущей вкладки. Если браузер полностью запретил это хранилище, новый секрет всё равно генерируется, но при перезагрузке может случайно совпасть с прошлым. Для обычного запуска через localhost с разрешённым хранилищем повтор исключён.

`startGame()` сбрасывает состояние и интерфейс. Обработчик нажатия кнопки «Проверить» проверяет ввод и сравнивает ответ с секретом. `addAttempt()` добавляет число в массив и выводит его в списке. `showMessage()` обновляет текст подсказки.

Для вывода используется `textContent`: данные воспринимаются как обычный текст, а не HTML.

## Соответствие заданию

| Требование | Реализация |
| --- | --- |
| Генерируется число | Случайное целое от 1 до 100 |
| Подсказки больше/меньше | Сравнение ответа с секретом |
| Игра заканчивается при угадывании | Блокировка ввода и кнопки проверки |
| Цветной фон | `background` в CSS для `body` |
| Число меняется при обновлении | Новый случайный секрет с исключением предыдущего через `sessionStorage` |
| Записываются введённые числа | Массив `guesses` и список попыток, повторы сохраняются |
| Поздравительная надпись | Картинка победы и «Число угадано!» при совпадении ответа с секретом |

## Ручная проверка

- Введи `0`: появится «Ах ты [картинка] — так нельзя!», счётчик попыток не изменится.
- Отправь пустое поле, `101`, `1.5`: появится обычная ошибка без картинки.
- После реакции на ноль введи допустимое число: сообщение сменится результатом попытки.
- При каждом неверном ответе появляется ровно одна картинка с подсказкой. При победе она сменяется картинкой победы, а при нажатии «Новая игра» любая картинка исчезает.
- Введи `1`, затем `100`: получи подсказки или победу на границе диапазона.
- Введи один неверный ответ дважды: обе попытки остаются в истории.
- Угадай число, сужая диапазон по подсказкам: появятся картинка победы и «Число угадано!», ввод отключится.
- Нажми «Новая игра»: история и счётчик очистятся, ввод станет доступен.
- Обнови страницу: начнётся новая игра с другим числом.
