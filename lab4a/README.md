# Лабораторная работа 4а — Котики против фото

Открой `index.html` в современном браузере двойным кликом. Установка пакетов и сервер не нужны.

## Правила

- Два человека играют по очереди на поле 5 × 5.
- Котик 🐱 заменяет крестик и начинает каждый раунд. Игрок с фотографией заменяет нолик.
- Побеждает тот, кто первым соберёт 3 своих символа подряд по горизонтали, вертикали или любой диагонали.
- Если поле заполнено и победителя нет, объявляется ничья.
- После раунда появляется окно результата. Нажми «Следующий раунд», чтобы продолжить.
- Если закрыть окно клавишей Escape, кнопка следующего раунда остаётся под полем.
- Счётчик раундов показывает количество завершённых игр, включая ничьи.
- Победы считаются отдельно. При ничьей счётчики побед не меняются.
- Обновление страницы сбрасывает поле и все счётчики.

## Файлы

- `index.html` — разметка страницы и окно результата.
- `style.css` — оформление и адаптация под небольшой экран.
- `script.js` — обработка ходов, проверка победы, счёт и новый раунд.

- `player-photo.png` — фотография второго игрока. При переносе игры копируй её вместе с остальными файлами.

## Как работает логика

Поле — массив из 25 элементов. В пустой клетке хранится `null`, после хода — `cat` или `photo`.
Индекс клетки вычисляется как `строка * 5 + столбец` (нумерация начинается с нуля).
После хода функция `findWinningCells` проверяет тройки в четырёх направлениях.
При победе или ничьей поле блокируется и обновляется счёт. Иначе ход переходит другому игроку.
Данные хранятся только в переменных JavaScript, поэтому исчезают при перезагрузке страницы.

Использованы HTML, CSS и чистый JavaScript без библиотек.
