# Лабораторная работа 5 — Счётчик кликов

Простая страница на React, JavaScript, HTML и CSS.

## Запуск

Нужен Node.js 20.19+ или 22.12+ (подойдёт установленный Node.js 24).

```sh
npm install
npm run dev
```

Открыть адрес из терминала (обычно http://127.0.0.1:5173).

## Как это работает

- `src/main.jsx` — React-компонент. `useState` хранит число, кнопки меняют его на 1.
- `useEffect` записывает значение в `localStorage` после изменения.
- При загрузке страницы начальное значение читается из `localStorage`; если сохранения нет, счётчик начинается с 0.
- Отрицательные значения разрешены.
- `src/style.css` — оформление и цветной фон.
- `index.html` — HTML-страница, в которую React выводит компонент.

Сохранение действует в том же браузере и по тому же адресу (включая порт). Очистка данных сайта удаляет сохранённое значение.

## Проверка

1. Нажать «+» несколько раз: число увеличивается на 1 за клик.
2. Нажать «-»: число уменьшается на 1, в том числе ниже нуля.
3. Обновить страницу: число должно остаться прежним.

Для сборки: `npm run build`. Готовые файлы появляются в `dist/`.
